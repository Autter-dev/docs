Connect one of your GitHub repositories to receive Autter feedback in the pull request workflow. If you want Autter to create a demo repository first, follow the [platform quickstart](/quickstart#try-a-demo-repository).

## Before you begin

You need an Autter account and permission to install a GitHub App on the target account or organization.

## Connect GitHub

<Steps>
  <Step title="Sign in to Autter">
    Open the [Autter platform](https://app.autter.dev/login) and sign in. Create a trial organization or open an existing organization.
  </Step>
  <Step title="Choose your own repository">
    Open repository selection and click **I have repositories to connect**.
  </Step>
  <Step title="Connect GitHub">
    Complete the GitHub authorization flow for the account or organization that owns your repository.
  </Step>
  <Step title="Grant repository access">
    Install the Autter GitHub App or review its existing access. Choose **Only select repositories**, include the repository you want to try, and approve the installation.
  </Step>
  <Step title="Add the repository to Autter">
    Return to Autter, select the repository, and click **Add 1 repository** when connecting a single repository.
  </Step>
  <Step title="Open or update a pull request">
    Use a connected repository and look for Autter feedback in the pull request.
  </Step>
</Steps>

## Verify the connection

Confirm that:

- the repository appears in the Autter platform after you add it to the organization
- the GitHub App has access to that repository
- a new or updated pull request starts an Autter review
- the review output appears in the pull request workflow

If the repository does not appear in Autter, verify the App's repository access in GitHub, then return to repository selection and add it. If no review appears, reconnect the repository in Autter if necessary.
